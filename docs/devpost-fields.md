## Project name
Onecut

## Tagline
A professional agent that cuts a messy workday down to exactly one next action.

## Elevator pitch / description
Solo founders do not fail from a lack of tasks. They fail because a broken day keeps sprouting Slack, inbox, meetings, and leftover promises. Chatbots make the pile longer. Calendar apps keep every block.

Onecut is a Professional-track Strands agent. It collects a synthetic founder day log, refuses a full plan if asked, and returns exactly one next action with a first physical step. Everything else is named as deferred, not forgotten.

The policy is deterministic: leftover promises beat new work; a broken day keeps the first promise; an intact deep-work block is protected. The live demo shows KEEP on the kept title and the Strands tool trace beside the cut.

This is new contest work. It is not Closeout, not a chatbot, not a day planner, and not live user data.

## Built with
AWS Strands Agents SDK, FastAPI, Python, deterministic policy, synthetic fixtures
